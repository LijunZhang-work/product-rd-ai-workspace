# 真实场景集成与证据规则修订记录

日期：2026-09-20｜性质：工作区文档设计、实施与 Review 记录。用户已授权按本窗口最近几轮共识设计、修改、检查并修正。本记录不代表公司产品代码已修改或真实设备已验证。

## 1. 修改前设计

当前工作区已有事实探查、AI 测试、共享观测能力和任务记录。新增 `真实场景集成验证` 作为跨模块的场景执行入口；通用方法保留在原模块，实际运行证据沿用 `任务记录` 的归属，不复制工具安装说明、事实报告或运行结果。

首个场景为“端到端用例与 POU 验证”：继承 WSL 双仓事实和 Windows XML 分析，以专业人员确认的真实业务用例建立边界与映射；先做不上板 POU 测试，再按条件实施设备接收、产品/EMAP 处理、跨核交接与 POU 执行采集，并将真实输入及状态回放。两条路线可以分别推进，完整场景交付时分别报告范围，不能以离线通过代替上板完成。

公共规则先改三处：编译数据库逐仓逐配置实查；BEH 证据按所证明的事实评估；用户反馈的最新进展与作者未核实的边界分开记录。随后修正下游入口、模板、旧限制和引用，最后检查本次改动的可达性、矛盾及证据来源。

## 3. 不同资料的维护责任

- 新场景目录：场景步骤、能力引用、场景特有映射/配置、验收和续接。
- `工具接入与共享能力`：工具方法唯一指南、BEH 已知问题、通用采集及导出方法。
- `总览与规则/参考规范`：证据可信度的统一规则；下游只补适用提醒与链接。
- `任务记录`：具体产品执行证据和多次运行索引。文档 Review 保存于本修订记录，不伪装产品运行。
- 历史资料、历史 ZIP 与此前验证日志：保留原始记录；不把既往时间的事实改写成今天的执行结果。正式入口说明当前适用规则。

## 5. Review 与修正

内容 Review 重新从总入口检查场景衔接，并对照 R01～R13 检查边界、证据和既有规则。发现并修正：

| 发现的问题 | 已完成的修正 |
| --- | --- |
| 共享指南旧任务指令仍限定不读取/重编 EMAP，容易覆盖本轮授权 | 改为承接已准备的匹配源码，按实际需要构建，并验证产品消费新依赖 |
| AI 解释等流程仍以早期 8 个 FB 为当前起点 | 保留历史基线，当前先核实已有 POU 入口和覆盖 |
| 不上板指南的全链要求可能挡住第一个 POU 局部用例 | 根据所声明范围选择步骤；POU 通过与全链通过分别报告 |
| 场景和共享指南可能各要求一份总报告 | 共享结果作为唯一任务报告章节或既有成果引用 |
| 既有增强探查记录链接到未单独保存的空 stdout 文件 | 保留历史路径说明，移除无效超链接，保留真实错误日志入口 |

| 文本补充处出现引用段落格式不完整 | 修正格式，并检查新入口可达性及链接 |
