## 2. 模块职责

### `services/beh-native-scene`

Java服务；唯一允许加载原始 JRE/JAR 并导出场景。

### `apps/web-workbench`

不含模型密钥和模型SDK；只使用 Gateway API。

### `services/code-intelligence`

独立于模型；支持增量索引和工具查询。

### `services/analysis-gateway`

屏蔽“文件任务包”与“直接Harness通信”的差别。

### `packages/contracts`

JSON Schema 和 TypeScript/Java绑定。字段含义只在此处定义。

## 4. 运行时依赖隔离

原始 BEH JRE/JAR 通过本地配置指向，记录 Hash，不复制到分析任务包。

## 5. 反编译参考代码

目录必须叫：

```text
recovered-java-reference
```

不得叫 `source` 或 `original-source`。每次反编译记录：

- 原JAR Hash；
- CFR版本；
- 参数；
-生成时间；
- 交叉检查备注。

## 6. 接口边界

任何服务跨边界只通过：

- JSON Schema；
- 本地HTTP/JSON-RPC；
- 明确文件包；
- 稳定工具契约。

不得让 Web 直接调用原始 JAR 内部类，也不得让 Skill 直接写 Workspace 内部数据库。
