# 总体软件架构与关键决策

                    │ NativeSceneBundle
┌───────────────────▼──────────────────────────┐
│ Workspace Gateway                            │
│ 工作区、缓存、任务、结果、权限、状态           │
└───────┬──────────────────┬───────────────────┘
        │                  │
        ▼                  ▼
┌───────────────┐  ┌──────────────────────────┐

                       │
                       ▼

                       │
                       ▼
             Web分析结果与代码联动

## 2. 关键决策 ADR

### ADR-001：原始 JAR 是唯一 BEH 事实源

不基于反编译代码重新实现第二套权威 Renderer。

### ADR-002：Original View 直接显示原生 Scene SVG

Web不重画正式 Node、Port、Relation和箭头。

### ADR-003：JCanvas 不进入 Headless 主架构

已验证无法实例化。选择、Hit Test和手绘由 Web 根据 hit-map 完成。

### ADR-004：Web前期不调用AI API

通过任务包与外置 Skill 解耦。右侧名称统一为“分析结果”。

### ADR-005：Analysis Gateway 抽象传输

```text
FileBundleAdapter（MVP）
HarnessAdapter（后期）
```

两者使用同一请求/结果契约。

### ADR-006：先 Explain，后 Compose

解释准确性、代码绑定和证据链未稳定前，不实现正式写入。

### ADR-007：Proposal First

任何AI图元或代码修改先成为Proposal，不直接影响正式工程。

### ADR-008：测试门禁先于阶段宣称完成

Web功能必须经过Playwright；原生场景必须有Golden对照；应用必须有Round-trip。

## 3. 核心服务

### Native Scene Service

输入：

```text
workspace配置 + 主入口XML + canvas/pou id
```

输出：

```text
NativeSceneBundle
```

### Workspace Gateway

- 路径校验；
- 任务目录；
- 结果目录；
- 缓存；
- 进度；
- 取消；
- Schema验证；
- 日志脱敏。

### Code Intelligence

- compilation database；
- symbol index；
- definitions/references；
- call graph；
- data-flow evidence；
- scene-code binding。

### Analysis Gateway

统一接口：

```text
prepareTask()
submitTask()
getTaskStatus()
loadResult()
```

MVP `submitTask()` 只落文件和生成命令说明，不调用模型。

## 4. Web 图层

```text
Layer 0：Native scene.svg
Layer 1：Hit/Selection
Layer 2：Annotation/Intent
Layer 3：Analysis Highlight
Layer 4：Proposal
```

## 5. 数据流

### Explain

```text
用户圈选
→ SelectionContext
→ AnalysisTaskBundle
→ External Skill查询代码
→ AnalysisResultBundle
→ Web显示和定位
```

### Compose

```text
用户指定区域/文字/草图
→ IntentBundle
→ Compose Skill
→ ProposalGraphOperations + CodePatch
→ Review
→ Native Apply
→ Save
→ Parse Back
→ Round-trip Compare
```

## 6. 可靠性设计

- 所有 Bundle 带 Schema 版本。
- 所有场景带 JAR/XML/Exporter Hash。
- 所有分析步骤带 Evidence。
- 所有长任务可取消。
- 所有 UNKNOWN 保留，不偷偷补全。
- 所有缓存可重建，不作为唯一事实源。
