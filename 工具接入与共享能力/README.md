# 工具接入与共享能力

BEH 原生能力、源码关联、运行观测及外部工具接入。

工具操作先看 [工具统一管理与使用指南](工具统一管理与使用指南.md)，已盘点结果只读 [工具状态与验收报告](工具状态与验收报告.md)。安装、路径、容器接入、调用与证据契约由主指南统一维护；报告尚未在用户电脑盘点时必须保持待验证。

业务能力先看 [能力索引](能力索引.md)。复用成熟工具，必要时增加适配；具体调用方式必须依据源码调查与运行验证。共享能力只维护一份，其他模块建立链接。
