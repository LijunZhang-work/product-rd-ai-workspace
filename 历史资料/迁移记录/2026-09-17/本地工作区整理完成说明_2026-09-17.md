## 文件怎么打开

ZIP 内的 `product-rd-ai-workspace.bundle` 是完整 Git 仓库备份，包含真实文件和历史。这样避免在压缩包中再存一份相同的大型附件。还原时只需要本机已安装 Git，不需要 GitHub、网络或 Git LFS。

解压 ZIP 后，可以在该目录运行下面两条命令（Windows 的 PowerShell、Git Bash，以及 macOS / Linux 终端均可）：

```bash
git clone product-rd-ai-workspace.bundle product-rd-ai-workspace
git -C product-rd-ai-workspace remote remove origin
```

第二条仅移除指向本地 bundle 的远程别名，不删除文件或版本。目标目录需要尚不存在。还原后打开 `product-rd-ai-workspace/README.md` 即可。

也提供 `restore-workspace.ps1` 和 `restore-workspace.sh` 两个便捷脚本；可分别通过 `powershell -File restore-workspace.ps1` 或 `sh restore-workspace.sh` 调用。脚本只调用本地 Git 并拒绝覆盖已有目标；Windows 脚本未在真实 Windows 上运行验证，跨平台恢复优先使用上面的 Git 命令。
