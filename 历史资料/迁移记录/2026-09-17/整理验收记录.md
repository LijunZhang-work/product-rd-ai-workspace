## 可重复核验

在仓库中使用 Python 3.9 或更新版本运行：

```bash
python tools/verify_workspace.py
```

脚本检查当前文件、Git 导入基线、ZIP 完整性和本地 Markdown 文件链接；不联网，不操作设备，不运行产品业务。只检查文档内可点击的本地文件链接，不验证外部网站或所有历史示例路径。

后续有意编辑已迁入资料时，应记录新版本并同步更新迁移清单中的当前校验值；原始来源校验值作为来源记录保留；导入基线与当前版本分别核对。
