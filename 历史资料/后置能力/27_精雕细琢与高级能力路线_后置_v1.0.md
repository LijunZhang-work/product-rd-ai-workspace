# 精雕细琢与高级能力路线（明确后置）

## 1. 为什么后置

以下能力有价值，但不应阻塞：

```text
Headless Scene
Web圈选
Task Bundle
AI Explain
代码绑定
测试门禁
```

## 2. 后置体验精修

- 高级深石墨/铜金主题；
-细腻动效；
-可配置面板布局；
-多屏；
-快捷键；
-命令面板；
-搜索体验；
-任务历史对比；
-导出报告；
-可访问性精修。

## 3. 高级图形能力

- Semantic View；
-ELK自动布局；
-复杂Relation聚合；
-数据流播放；
-缩略图；
-超大画布虚拟化精修；
-多层图。

这些是辅助视图，不替代原生Scene事实源。

## 4. 高级手绘

- 自由手绘视觉理解；
-草图形状识别；
-手写文字；
-笔迹与图元吸附；
-多笔意图；
-视觉模型交叉确认。

复杂Freehand在此阶段才进入自动语义。

## 5. 高级Compose

- 更多Verified Components；
-局部重构；
-多方案比较；
-自动测试生成；
-失败自动回滚建议；
-跨POU修改；
-代码和图元同步重构。

## 6. 协作

- 多人Review；
-评论；
-审批；
-版本差异；
-权限；
-审计；
-远程部署。

## 7. 精修进入条件

只有以下全部稳定：

- Explain质量；
-大项目稳定；
-Playwright回归；
-代码绑定；
-Proposal安全；
-Round-trip；

才投入大规模视觉/交互精修。

## 8. 防止精雕泥潭

每个精修任务必须说明：

```text
解决的真实用户问题
可测指标
不影响的核心契约
回归范围
```

仅“更炫”“更高级”不得成为前期优先任务。
