# 任务记录模板

这是后续任务的记录模板，不是已执行任务，也不是要求所有工具采用统一 Schema。

| 项目 | 填写内容 |
| --- | --- |
| 任务 | 标识、业务问题、范围、状态 |
| 输入与基线 | 需求、源码/图元/工具/配置版本和对应关系 |
| 场景与预期 | 触发入口、步骤、独立预期及依据 |
| 运行列表 | 每次运行的编号、环境、时间、执行结果及异常 |
| 工具角色 | 网页、北向、南向 Python、专用 RS-485、BEH、日志/报文分别记录 |
| 证据位置 | 原始包、Trace、截图、值记录、解析结果及实际取得的校验值 |
| AI解释 | 结论、来源、适用条件、推断和未覆盖范围 |
| 定位与开发 | 定位材料、候选修改、提交与回归记录 |

同一任务可以有多次运行。组件自身的发行验证仍归该组件；针对产品的运行在这里建立索引。一个 run_id 只能帮助关联，不直接证明事件因果。
