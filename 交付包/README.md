# 交付包

正式资料以工作区根目录及各模块为准。这里保存按用途生成的副本，不作为日常编辑入口。

2026-09-20 起，后续完整 ZIP 同时提供“确定基线→本次交付”的文件变更清单、文本差异和阅读说明；它们在正式工作区的 `总览与规则/交付差异/<交付ID>/` 展开保存并随包提供。本地 AI 另行比较同一基线→电脑本地改动，再进行三方合并。基线身份、缺失文件处理和同步回执统一遵循 [归档与同步规则](../总览与规则/归档与同步规则.md#交付快照差异与本地合并)。

目前 GitHub 基线尚未取得。本次提供 2026-09-19 上一交付快照 P → 2026-09-20 本次交付 N 的[变更说明、清单与文本差异](../总览与规则/交付差异/2026-09-20_完整工作区/变更说明.md)，不冒充 GitHub 实际差异；本地 AI 仍需核对真实远程提交和本地修改。

| 子目录 | 用途 |
| --- | --- |
| 当前版本 | 唯一当前完整展开版，解压后直接打开 README |
| 专项包 | 依赖完整的专项任务或源码发布副本；使用前核对其声明的版本和适用范围 |
| 历史版本 | 整理前的 Git 包、外层整包、旧 HPT 总包 |

历史 Git 包保留原提交历史；旧“完整文件夹”缺少后来新增的 WSL 资料和增强 v1.1 更新，不能作为当前版本。

完整展开版 ZIP 不重复收录这里的 ZIP 文件，只保留本说明，因此没有“下载新包又套进旧整包”的情况。需要恢复旧 Git 历史时，在工作区的历史交付区单独取包；日常阅读和使用正式模块不需要它。
