# 定位材料模板

用途：让开发者和 AI 可以回到同一次失败，继续查证和修复。此文件是模板，没有真实故障结论。

| 材料 | 填写内容 |
| --- | --- |
| 对应任务与运行 | 任务索引、run_id、发生时间和真实来源 |
| 版本与环境 | 源码提交及未提交差异、运行物、图元工程、配置、设备或模拟环境 |
| 预期与依据 | 应出现的行为、适用需求/协议/独立规则；未知写明 |
| 复现条件 | 前置状态、输入、实际步骤、是否受断点影响 |
| 失败位置 | 最后一个已证实正确的观察点、首个差异及原始证据引用 |
| 源码线索 | 函数/文件/对象身份与版本；有待证实的原因独立列出 |
| 最小补测 | 要区分什么原因、改什么条件、看什么结果 |
| 修复与验证 | 变更提交、回归范围、实际结果和剩余缺口 |

不复制或改写密封原始证据；通过任务索引引用。浏览器 Trace 支撑对应网页操作的回看，真实设备值和跨工具因果需要各自证据。
